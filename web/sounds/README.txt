Optional sound overrides.

The app synthesises all of its sounds. If you drop any of these files in this
folder they are used instead:

  insert.mp3  - one shell being pushed into the tube (played once per shell)
  rack.mp3    - pump action after loading
  live.mp3    - live round fired
  blank.mp3   - blank fired (click)

Only use recordings you have the right to use.
